What to upload

Filenames are matched loosely: case, spaces, underscores and a trailing date are all fine, so Retails_29-08-2026.xlsx works. Each file's columns are checked before it is accepted, so a mislabelled export is rejected rather than silently scored.

A missing optional file does not stop the run. Its lines are marked not scored with the missing file named, and are excluded from the index denominator rather than scored zero — so a data gap never looks like a failing branch.

Uploading daily or mid-month

Month-to-date extracts are fine. The audit detects the period from the data and pro-rates monthly volume norms — retail target, retails per consultant, order bank cover — to the days covered, so a 10-day pull is not judged against a full month's target. Conversion percentages need no adjustment.

Every run is recorded, so the trend page shows whether the corrective actions are working. Re-running the same period replaces that row rather than adding a duplicate.

Physical Audit Sheet

The DMS cannot tell you whether the display cars are clean, whether consultants carry a current price list, or whether the walk-in register is being maintained. Those have to be walked and seen.

On the phone. Open {{ url_for('mobile.home', _external=True) }} on the device you carry round the showroom, pick the branch and tap through the 62 items. Answers save as you go and survive a dead spot in the delivery bay. Submit at the end and the audit waits on the server.

Export it. At the end of the walk, tap Export as Excel sheet. One branch, one sheet. That file is the record of the audit.

On the laptop. Upload the exported sheet in the same drop box as the DMS extracts, in the same go, and run. Several sheets — one per branch — can go in together; they are merged automatically. Keep Physical_Audit_Sheet at the start of the filename and a branch suffix or a (1) makes no difference.
